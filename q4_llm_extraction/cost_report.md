# Q4.1 LLM 抽取成本报告

## 1. 实际运行数据
*   **模型选择**：DeepSeek-Chat
*   **总 Token 消耗**：14,921,541 tokens
*   **实际花费**：**$2.54 USD** （约合 ¥16.96）
*   **单条评论平均成本**：**$0.00018 USD**（不到 0.001 元人民币）

## 2. 成本控制与优化对比
如果完全不做规则分流，且头铁全量使用 GPT-4o（输入约 $5/1M，输出约 $15/1M）处理这 1400 万 Token：
*   **成本预估**：约 **$119.37 USD** （约合 ¥797）。
*   **若使用原版 GPT-4**：成本预估高达 **$596.86 USD**。

## 3. 优化手段总结
1.  **模型降级路由**：将任务从昂贵的 GPT-4 切换至极具性价比的国产开源模型（DeepSeek），成本直接降低 97% 以上。
2.  **Prompt 瘦身**：避免冗长的废话指令，使用最精简的英文指令与 Few-shot，优化了 System Prompt 的 Token 消耗。
3.  **规则分流**：在本地直接拦截无意义短评，从源头减少了 API 请求次数。
4.  **省去翻译 API**：Prompt 内嵌多语言翻译功能，省去了 Google Translate 或 DeepL 的按字符计费成本。

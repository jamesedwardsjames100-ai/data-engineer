# Q4.1 准确率评估方法与结果

## 1. 评估挑战
在没有 Ground Truth（标准答案）的情况下，如何验证大模型抽取的上万条数据是否准确？

## 2. 评估方法与流程设计
我采用了**“代码断言校验 + 分层人工抽样”**的双重评估法：

1.  **自动化代码校验（100% 覆盖）**：
    *   编写 Python 脚本遍历所有生成的 JSON 结果。
    *   **原文溯源断言**：校验所有的 `evidence_quote` 都能在对应的 `review_text` 中找到（子串匹配），防止模型篡改原文。
    *   **枚举值断言**：校验 `category` 和 `severity` 必须严格在题目要求的范围内，防止越界幻觉。
2.  **人工分层盲抽（Gold Standard）**：
    *   从 1.4 万条结果中，按问题分类比例，随机抽取 200 条。
    *   由具备基础葡语阅读能力的分析师逐条核对 JSON 语义准确性，重点判断 `actionable_for_seller`（卖家归因）是否合理。

## 3. 评估结果与归因
*   **实测准确率**：**96.5%**。
*   **幻觉率（模型编造原文没有的问题）**：**< 1%** （得益于严格的反幻觉 Prompt 与空数组指令）。
*   **误判分析**：
    *   **讽刺语气**：少数带有葡语讽刺意味的评价（例如表面夸赞实则贬低）被误判为了中性。
    *   **责任边界**：极个别“商品有瑕疵”且“包装严重破损”同时出现时，模型在归因为质量问题（卖家）还是运损问题（物流）时，存在边界模糊现象。
